# Interview Engine - Task 11: Core Decision Engine

## Overview
AI-powered interview platform with a dynamic decision engine that controls interview flow in real time.

## Features
- Next question selection based on topic and difficulty
- Follow-up triggering for weak answers
- Automatic difficulty adjustment
- Smart interview termination

## Tech Stack
- Node.js, Express.js
- Jest for testing
- REST API

## Installation
npm install
npm run dev

## API Endpoints
- POST /api/interview/start
- POST /api/interview/answer
- GET /api/interview/status/:sessionId

## Testing
npm test
